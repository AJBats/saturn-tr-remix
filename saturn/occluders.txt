# Solid boxes, made into build/gen/occluders.h by tools/occluders.py.
#
# A box names a shape nothing can be seen through: a pillar, a mass of rock between
# rooms, or a flat rectangle (x0 = x1, y0 = y1 or z0 = z1), which takes the side of its
# plane it can be seen from last (+x, -y ...). What lies wholly behind it on the frame
# isn't drawn: a portal isn't walked through, a room face isn't made (renderer/rooms.h).
# World units, as room vertices have them.
#
# A box must be solid from every side it can be seen from, in every state of the
# level (a flood's rooms too). One that sticks out of the real thing cuts away what
# should show: python -I tools/occluders.py check LEVEL tests one against the rooms.
#
# level       x0     x1     y0     y1     z0     z1
